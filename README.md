## 📌 Descripción del proyecto

Este proyecto es una **aplicación web** que permite registrar, gestionar y visualizar información de **alumnos y reservas** de salas de cómputo en una institución educativa.

Se ha desarrollado con tecnologías modernas como **HTML, CSS, JavaScript y Bootstrap**, priorizando una experiencia intuitiva y responsiva, accesible desde cualquier navegador moderno.

---

## ✨ Funcionalidades

![imagen](https://github.com/user-attachments/assets/41c97798-917a-42f2-a4a8-a8dbad8ac7d2)

- Registro de alumnos con validación de datos.
- Registro de encargados de la sala respectiva.
- Registro de solicitudes por parte de estudiantes.
- Redirección automatizada y mensajes de confirmación tras envíos.
- Visualización de reportes intermedios y finales.
- Control de acceso (entrada/salida) con matrícula y horarios.
- Interfaz adaptable con diseño responsivo vía Bootstrap.
- Interacción diferenciada por tipo de usuario (Estudiante / Encargado).

## 🎬 ¿Cómo pueden usarlo los usuarios?

1. **Clonar el repositorio:**

   ```bash
   git clone https://github.com/Veca-LAG/TecnologiaWebEquipo.git

    Abrir el archivo index.html en un navegador web.

    Explorar las funciones según el tipo de usuario:

👮 Encargado / Guardia

    Registrar solicitudes de acceso ingresando la matrícula del estudiante.

    El sistema autocompleta la información desde la base de datos.

    Registrar fecha y hora de entrada y salida.

    Consultar reportes de todas las solicitudes realizadas.

🎓 Estudiante

    Consultar si tiene una reserva activa.

    Visualizar su hora asignada de entrada y salida.

    Ver mensajes de aceptación o rechazo de la reserva.

    ✅ No requiere instalación de software adicional. Solo se necesita un navegador web.
